# Data Artifacts

This directory stores generated benchmark artifacts, including datasets, trained models, metrics, and generated plots.

## Datasets
- `train_{fraction}.extxyz`: Training structures with energies and forces, split into fractions (10, 40, 70, 100) to evaluate data scaling.
- `val.extxyz`: Validation structures with energies and forces.
- `test.extxyz`: Held-out test structures with energies and forces.

## Models & Metrics
- `ace_model_{fraction}.pth` / `mace_model_{fraction}.pth`: Trained PyTorch model weights for ACE and MACE.
- `ace_metrics_{fraction}.csv` / `mace_metrics_{fraction}.csv`: Per-epoch train/validation metrics.
- `ace_test_metrics_{fraction}.csv` / `mace_test_metrics_{fraction}.csv`: Held-out test metrics.
- `inference_metrics.csv`: Forward-pass inference overhead speeds per molecule.

## Plots
- `final_comparison_plot.png`: Baseline Error Curves.
- `data_scaling_plot.png`: Data Volume Scaling (Experiment A).
- `cost_vs_accuracy_plot.png`: Computational Cost vs Accuracy (Experiment B).
- `parity_plot.png`: Energy and force prediction parity plots.
- `mace_md_stability.png`: Molecular dynamics stability plot.

## Notes
- These files are generated by notebooks and may be overwritten on reruns.
- Datasets (`*.extxyz`) and model files (`*.pth`, `*.pt`) are git-ignored due to their size.
- Plots (`*.png`), metrics (`*.csv`), and this README are tracked by version control.
