# Data Artifacts

This directory stores generated benchmark artifacts.

## Files
- `train.extxyz`: Training structures with energies and forces.
- `val.extxyz`: Validation structures with energies and forces.
- `test.extxyz`: Held-out test structures with energies and forces.
- `ace_metrics.csv`: ACE per-epoch train/validation metrics.
- `mace_metrics.csv`: MACE per-epoch train/validation metrics.
- `ace_test_metrics.csv`: ACE held-out test metrics (single row).
- `mace_test_metrics.csv`: MACE held-out test metrics (single row).

## Notes
- These files are generated by notebooks and may be overwritten on reruns.
- Energy/force labels must be preserved through `SinglePointCalculator` before writing extxyz files.
